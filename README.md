# 💘 LoveLottery - Love Prediction & Lottery Wheel Web App

A fun, interactive, full-stack **Love Prediction Lottery Wheel** web application where users enter their name and their crush/lover's name, spin an animated 3D lottery wheel, and receive hilarious Bengali/English love compatibility fortunes!

---

## 🌟 Key Features

- **Interactive 3D Canvas Lottery Wheel**: Smooth physics spinning animation with 16 dynamic sector options and confetti particle FX.
- **Hilarious Love Predictions**: Funny Bengali love fortune messages, compatibility scores, and 1-click WhatsApp share cards.
- **Fast & Responsive UI**: Glassmorphism design with cyberpunk neon themes, live activity ticker, and audio sound synthesis.
- **Vercel Zero-Config Deployment**: Serverless architecture ready for instant deployment.

## 🚀 Quick Start & Local Setup

### 1. Clone & Navigate
```bash
git clone https://github.com/zeeshan-ux-AI/love-prediction-lottery.git
cd love-prediction-lottery
```

### 2. Run Local Python Server
```bash
python3 -m http.server 8000 --directory public
```
Open `http://localhost:8000` in your browser to play with the Love Lottery Wheel!

---

## 🌐 Deploy to Vercel

1. Import repository on [Vercel](https://vercel.com/new).
2. Click **Deploy**!
